# 部署与配置

## 干净环境一键复现

依赖使用 uv 管理，并且同时提供两种锁定形式。

第一种是 uv 的锁定清单，配合冻结安装参数使用，命令是先同步再运行。
第二种是导出出来的 requirements 文本文件，供不使用 uv 的人作为参考。

Python 版本要求三点十一以上，开发与持续集成环境使用三点十三。

## 配置

配置采用 TOML 格式，默认文件位于 configs 目录下的 default 点 toml。
这份默认配置是离线安全档，不依赖任何模型与网络。

要跑真实模型，把 local 点 toml 点 example 复制成 local 点 toml 后使用。
该文件已经被 gitignore 排除，不会进入版本库。

配置来源的优先级从低到高是：内置默认值、配置文件、环境变量。
环境变量使用 QUASAR 前缀，嵌套字段用双下划线分隔。

## 启动服务

启动命令是 quasar serve，默认监听 127 点 0 点 0 点 1 的 8000 端口。
启动后访问根路径可以看到内置的 Web 控制台。

控制台是一个单文件 HTML，内联样式与脚本，不依赖任何外部资源，
也不使用任何表情符号作为功能图标。

## 自诊断

命令 quasar doctor 会逐项检查 Python 版本、依赖是否齐全、配置是否合法、
数据目录是否可写、外部模型服务是否可达、知识库中有多少文档与知识块。
每条失败的检查都会附带一条可以直接执行的修复建议。

## 健康检查接口

服务提供健康检查接口，返回整体状态与每个组件的明细。
接口层还有一条自诊断接口，除了组件健康之外还会检查依赖与路径。

## 评测

命令 quasar eval 会在一个临时目录里新建完全隔离的索引，
既不读也不写生产索引，然后跑黄金集并输出报告。

评测必须使用独立索引，原因是复用生产库会让之前跑过的冒烟测试污染语料，
导致指标掉到零却没有任何异常抛出。
